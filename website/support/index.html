Frequently asked questions

I forgot my master password.

Unfortunately it cannot be recovered or reset. SecretDoor has no server and keeps no copy of your password, which is exactly what keeps your vault private. If you set a hint, tap “Show master password hint” on the unlock screen. If you have a backup, it needs the master password that was current when the backup was made.

I got a new phone. How do I move my vault?

Save a backup file on the old phone (Settings > Vault > Backup), copy it to the new phone, install SecretDoor and choose Restore from backup when creating the vault.

Does SecretDoor sync between my devices?

Not at the moment. Each vault lives on one device, and a backup file is how you move or copy it.
