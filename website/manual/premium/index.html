Premium

"Premium" is a label that SecretDoor inherits from the app it is based on. In SecretDoor, every feature that exists works without paying: authenticator codes, attachments, the generator, SSH keys, passkeys and encrypted backups.

There is no account, so there is no subscription to manage. If an optional paid add-on is offered in the future (for example automatic cloud backups handled for you), it will be clearly described in the app before you can buy it, and the free features will keep working. Making backups by hand and automatic backups to a file you choose are free and will stay free.

SecretDoor is free software. You can read exactly what it does in the source code.
