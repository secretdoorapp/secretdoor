# Managing vaults

SecretDoor can hold several vaults on one phone, for example a personal and a work vault. Each vault
has its own master password and is encrypted separately. Only the vault you unlock is readable.

Open **Settings > Vault > Manage vaults**, or choose **Manage vaults** in the menu on the My vault
screen.

## Rename a vault

Tap the menu on a vault and choose **Rename vault**. A vault without a name is shown as "My
vault". Names only help you tell vaults apart; they are not part of the encryption.

## Delete a vault

Tap the menu on a vault and choose **Delete vault**, then enter **that vault's master password**.
The vault's items, folders and attachments are permanently erased from the phone. This cannot be
undone, but backups you made earlier are not affected.

If you delete the vault you are using, SecretDoor switches to another vault. If it was your only
vault, you return to the Create vault screen.

## Add a vault

- **Create a new vault**: choose a master password for a new, empty vault. Close the screen with
  the **X** to cancel.
- **Import backup**: add a SecretDoor backup as a separate vault. It keeps its own master password.
  See [Importing data](importing-data.md).

## Switching vaults

When there is more than one vault, the vault picker appears at the top of the My vault screen and on
the unlock screen. Choose the vault you want; you will be asked for its master password if it is
locked.
