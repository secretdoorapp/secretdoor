# Master password re-prompt

**Master password re-prompt** is an option you can turn on for a single item. When it is on,
SecretDoor asks for your master password again before it will:

- show or copy the item's secrets (password, card number, security code, private key, hidden
  fields),
- fill the item into an app or website with autofill.

## Why use it

Your vault is already unlocked while you use the app. If someone borrows your unlocked phone, or
the app is left open, they could read everything in it. Re-prompt adds a second check for the items
that matter most, such as banking logins or recovery codes.

It does **not** make the item's encryption any stronger. It is a safeguard against someone using
your already-unlocked vault, not against someone who has the vault file and your master password.

## How to turn it on

1. Open the item and tap **Edit**.
2. Switch on **Master password re-prompt**.
3. Save.

Turn it off the same way.
